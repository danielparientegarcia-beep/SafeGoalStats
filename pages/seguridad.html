Seguridad

Seguridad de la plataforma

La seguridad es uno de los pilares fundamentales del proyecto SafeGoalStats. Esta página explica las medidas básicas que se aplican para proteger a los usuarios y la información del sistema.

El objetivo es concienciar sobre la importancia de la ciberseguridad y ofrecer una plataforma fiable y educativa.

Servidor web Apache

SafeGoalStats utiliza Apache como servidor web encargado de recibir peticiones y servir páginas de forma segura.

Permite configurar permisos, rutas y futuras conexiones cifradas HTTPS.

Protección de datos

El proyecto está diseñado para que los datos personales no sean accesibles sin autorización.

En versiones futuras las contraseñas estarán cifradas y habrá autenticación segura.

Amenazas comunes

Se tienen en cuenta ataques habituales como SQL Injection, XSS o accesos no autorizados.

Se aplican buenas prácticas como validación de datos y control de errores.

Mejoras futuras

Se podrán añadir tokens, control de sesiones y alertas de seguridad personalizadas.
