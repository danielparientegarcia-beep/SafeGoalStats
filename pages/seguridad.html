Seguridad de la plataforma

La seguridad es uno de los pilares fundamentales del proyecto SafeGoalStats. Esta página explica las medidas básicas que se aplican para proteger a los usuarios y la información del sistema.

El objetivo es concienciar sobre la importancia de la ciberseguridad y ofrecer una plataforma fiable y educativa.

Servidor web Apache

SafeGoalStats utiliza Apache como servidor web, encargado de recibir las peticiones de los usuarios y servir las páginas de forma controlada y segura.

Apache permite configurar permisos, rutas de acceso y, en un futuro, conexiones cifradas mediante HTTPS.

Protección de datos del usuario

El proyecto está diseñado para que los datos personales de los usuarios estén protegidos y no sean accesibles sin autorización.

En futuras versiones, las contraseñas se almacenarán cifradas y se implementará un sistema de autenticación seguro.

Prevención de amenazas comunes

SafeGoalStats tiene en cuenta amenazas habituales en aplicaciones web como la inyección SQL, ataques XSS o el acceso no autorizado.

Para ello, se aplican buenas prácticas como la validación de datos, la separación de archivos y el control de errores.

Mejoras de seguridad futuras

En el futuro, la plataforma podrá incorporar medidas avanzadas como autenticación con tokens, control de sesiones y alertas de seguridad personalizadas.

Estas mejoras permitirán ofrecer una experiencia más segura y profesional a los usuarios.
