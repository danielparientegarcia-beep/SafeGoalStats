# SafeGoalStats

SafeGoalStats es una página web de estadísticas de fútbol que permite consultar información sobre partidos, equipos y jugadores de forma clara y organizada.

## Descripción

Este repositorio contiene la parte visual de la aplicación (frontend). Es la interfaz con la que interactúa el usuario y desde la que se muestran los datos.

## Funcionalidades

- Consulta de estadísticas de fútbol
- Visualización de equipos y jugadores
- Interfaz sencilla y rápida de usar
- Conexión con la API del proyecto

## Conexión con la API

Este proyecto se conecta con la API de SafeGoalStats-API, que es la encargada de proporcionar los datos.

## Estructura

- Archivos principales de la web
- Carpeta de estilos
- Carpeta de scripts
- Recursos e imágenes

## Uso

1. Clonar el repositorio
2. Abrirlo en un servidor local o desplegarlo en un hosting
3. Asegurarse de que la API esté en funcionamiento
